# SRoMCaH

This repository contains a simple but polished static landing page for SRoMCaH.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit:

- http://localhost:8000

## Files

- `index.html` — main page structure
- `styles.css` — site styling and responsive layout
- `script.js` — small enhancements for navigation and footer year

This is ready to be used as a lightweight static website and can also be deployed to GitHub Pages.
